# Controle de Medicamentos

Sistema desenvolvido para gerenciamento de medicamentos, pacientes, fornecedores, funcionários e controle de estoque.

O projeto tem como objetivo facilitar o registro e acompanhamento de entradas e saídas de medicamentos, garantindo maior organização no controle de estoque e no atendimento aos pacientes.

## Funcionalidades

- Cadastro de fornecedores
- Cadastro de pacientes
- Cadastro de medicamentos
- Cadastro de funcionários
- Controle de estoque
- Registro de entradas de medicamentos
- Registro de saídas de medicamentos
- Validações de dados e regras de negócio

## Tecnologias

- .NET
- C#
- Arquitetura em 3 camadas
- Persistência de dados em arquivo

## Objetivo Acadêmico

Projeto desenvolvido para aplicação de conceitos de orientação a objetos, arquitetura em camadas, versionamento com Git/GitHub e boas práticas de desenvolvimento.
